Skills

Skills are reusable know-how packs Aura loads on demand — the same mechanism behind the built-in robot-shift-notes skill. Write one for any repeatable question you keep asking (a keyword glossary, a checklist, an output format) and Aura will reach for it automatically when it's relevant. No code editing required.
